# Интерфейс кредитного калькулятора

React, TypeScript и Vite: предварительный расчёт платежей, авторизация, заявки и работа с договором.

Установка и запуск: `npm ci`, затем `npm run dev`. Интерфейс доступен на <http://localhost:3000>; запросы `/api` перенаправляются на gateway по адресу `http://localhost:8080`.

Проверки: `npm test`, `npm run lint`, `npm run build`.

Устройство проекта, процесс разработки и запуск инфраструктуры описаны в [основном README](../README.md).
